# tannerholman.space

Personal site for Tanner Holman: a single landing page, an ink drawing of his cartwheel's straddle in a quiet high desert, with his handwritten name and two links.

Static files, no build step. Deployed via GitHub Pages from `main`, served at [tannerholman.space](https://tannerholman.space) (custom domain set via `CNAME`).

## Structure

```
index.html                  # the landing page: layout script, name (signature paths), line and links, all inline
art/                        # the drawing in layers: land0–2 (one wide strip of desert in three tiles), bankL, bankR,
                            # small (the cloud over the mesa), sun, hero (the figure in colour)
fonts/                      # Questrial, self-hosted (SIL Open Font License)
og-5.jpg, og-5-wide.jpg     # the link preview pictures, 1200 × 1200 and 1200 × 630 (rename on change so caches refresh)
favicon.svg, favicon.ico
CNAME                       # tannerholman.space
print/, tools/, og-4*.jpg   # the previous landing (the woodblock print); no longer used by index.html
60days-ofstanding/          # standalone: 60 days of standing
mothers-day-2026/           # standalone: Mother's Day 2026
```

## The landing (October 2026: the paper landing)

A quiet page on oat paper (#F9F5EC): links at the top, the handwritten name at about 35% of the screen with one
line under it, two cloud banks framing them (one off the top-left edge, one off the right edge with the sun peeking
over it), and the land along the bottom with the figure in full colour. Everything but the figure is one brown ink
(#8C6A58).

- **Edge to edge.** html, body and the art all sit on the paper colour, with viewport-fit=cover, so the strip behind
  the iPhone status bar and the area behind Safari's toolbar match the page. The land is one wide strip (the phone's
  view in the middle, more desert either side), so wider screens see more desert, never bars.
- **Layout** is computed in `layout()` in drawing units (the phone design is 900 units wide; u = CSS px per unit).
  Portrait screens get the phone composition (scaled to fit 900 × 1950, extra width shows more desert); others get the
  desktop one (figure a little right of centre, clouds sized to the screen).
- **Following a link** dissolves the page to paper over 0.7 s, then navigates (GoatCounter counts the click).
- **Still only for now.** The animation (the cartwheel as a smooth silhouette with a short trail, ghosts fading as he
  lands, the colour sketched in from the hands up) is prototyped but not yet in the page.

The art is generated by the drawing scripts (ink.js, land.js, layers.js), which are not in this repo.

## Local development

Serve the folder over HTTP (for example `python3 -m http.server`) and open `index.html`; the layers load from `/art/` and the font from `/fonts/` at the site root.

## Deployment

Push to `main`. GitHub Pages rebuilds in about a minute.
